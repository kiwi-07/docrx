# Roadmap

## Now (0.1.x)

- Stable static Dockerfile analysis
- Rich terminal UX
- Rule explainability
- Non-destructive fixes (`fix` / `suggest`)
- Before/after comparisons
- GitHub Action with PR commenting
- `badge` and `format` CLI commands
- Published on PyPI (`pip install dockrx`)
- Live web playground + API

## Next

- Image inspection / layer-size analysis
- More auto-fix coverage
- Better score prediction after fixes
- CLI helpers for scaffolding local rules (`dockrx rule new` / `init`)

## Later

- Rich HTML reports
- Remote rule packs
- VS Code extension
- Real image/layer metrics in `dockrx compare`
